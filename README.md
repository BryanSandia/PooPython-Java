# 🎮 Informe Teórico-Práctico: POO en Java vs Python
> Caso de estudio: Sistema de Jugadores para entorno PVP

## 📖 Descripción
Este repositorio contiene el desarrollo y la documentación del entregable académico **"Informe teórico/práctico de POO en Python"**, cuyo objetivo es comparar y aplicar los conceptos fundamentales de la Programación Orientada a Objetos (POO) entre **Java** y **Python**.

Como ejemplo práctico unificador, se implementa una clase `Jugador` (vida, daño, nombre, ID) con su constructor, métodos de lógica, encapsulamiento y representación textual, permitiendo visualizar cómo cada lenguaje aborda los mismos principios con filosofías de diseño distintas.

## 🎯 Objetivo de la Actividad
- Analizar la implementación de clases, atributos, métodos, constructores y niveles de acceso en Python.
- Comparar sintaxis, estrategias y buenas prácticas entre Java (compilado a bytecode/JVM) y Python (interpretado/PVM).
- Documentar ventajas, desventajas y casos de uso recomendados para cada lenguaje en entornos POO.

## 🧠 Conceptos Clave Explorados
✅ Definición de clases y objetos  
✅ Constructores (`Java: nombre_clase()` vs `Python: __init__()`)  
✅ Encapsulamiento y niveles de acceso (`private/protected/public` vs `_nombre` / `__nombre`)  
✅ Getters & Setters vs `@property` en Python  
✅ Representación textual (`toString()` vs `__str__()` / `__repr__()`)  
✅ Instanciación, invocación de métodos y ciclo de vida de objetos  
✅ Comparativa estratégica: rendimiento, tipado, verbosidad y ecosistema
